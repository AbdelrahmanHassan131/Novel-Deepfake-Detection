## 2. Confirmed Defects and Implemented Resolutions

### P1: Colab Workflow Commands and Execution Setup
- **Defects Identified:**
  1. `COLAB_RGB_LABEL_SMOOTHING_AB.md` used `--amp_train`, which is not an option in `train.py`.
  2. Calibration in Cell 4 targeted `<run>/best_dev_predictions.csv`, but `CheckpointHook` writes to `<run>/checkpoints/best_dev_predictions.csv`.
  3. Cell 6 attempted to import repo modules directly without adding `REPO_ROOT` to `sys.path` in the notebook Python kernel.
  4. Cell 1 git commands lacked fail-fast checks (could continue on failed fetch or branch mismatch).
  5. Cell 6 overwrote a static output filename (`label_smoothing_ab_comparison.json`) on subsequent runs.
- **Implemented Fixes:**
  - Replaced `--amp_train` with supported flags: `--use_amp --amp_dtype fp16` across all training invocations.
  - Corrected calibration paths to `<run>/checkpoints/best_dev_predictions.csv`.
  - Added `sys.path.insert(0, str(REPO_ROOT))` in Cell 1 and Cell 6.
  - Added fast-forward git update safeguards (`git fetch`, checkout branch, fail fast on dirty working trees or diverged commits).
  - Generated unique output artifacts per experiment pair: `comparison_{EXP_TIMESTAMP}.json` and `comparison_{EXP_TIMESTAMP}.md`.
  - Added OOM handling instructions specifying fresh run ID creation for affected arms while preserving failure artifacts.

### P1: Folder-Mode Validation Provenance & Calibration Safeguards
- **Defect Identified:**
  - Folder dataset records generated by `base_dataset.py` have `split='unknown'`. When passed to `CheckpointHook`, these records retained `split='unknown'`, causing `calibrate(..., score_space='logit')` to fail-closed with:
    `Threshold calibration accepts only development splits ['dev', 'dev_calibration', 'external_dev', 'val'], got ['unknown']`.
- **Implemented Fix:**
  - In [training/hooks/checkpoint_hook.py](file:///g:/Master%27s%20Of%20Science%20Computer%20Engineering/thesis%20deepfake%20detection/Thesis%20Revisions%20SP/First%20revesion/Novel%20Deepfake%20Detection/training/hooks/checkpoint_hook.py), records exported at the trusted validation boundary with `split in ('unknown', '', None)` are assigned `split='dev'`, `folder_role='dev'`, and `independence_status='unverified_dev_folder'`.
  - Unknown group/source metadata is preserved without manufacturing fake IDs or claiming unverified content audits.
  - Manifest records with explicit splits (e.g., `split='test'`) are strictly preserved and never relabeled as `dev`.

### P1: Comparison Identity Verification & Checkpoint Binding
- **Defect Identified:**
  - The comparison in Cell 6 previously loaded thresholds without verifying checkpoint hashes, only inspected the first row's hash, and aligned samples by ID without verifying file paths.
- **Implemented Fix:**
  - Created [compare_evaluation_runs](file:///g:/Master%27s%20Of%20Science%20Computer%20Engineering/thesis%20deepfake%20detection/Thesis%20Revisions%20SP/First%20revesion/Novel%20Deepfake%20Detection/evaluation/generalization.py) and routed both [analyze_predictions.py](file:///g:/Master%27s%20Of%20Science%20Computer%20Engineering/thesis%20deepfake%20detection/Thesis%20Revisions%20SP/First%20revesion/Novel%20Deepfake%20Detection/analyze_predictions.py) (`compare_ab` action) and Cell 6 through it.
  - Enforced row-wide checkpoint hash verification (every row in the prediction CSV must match the arm's `best.pth` SHA256 digest).
  - Enforced threshold checkpoint hash binding.
  - Aligned cohorts on canonical paths and labels in addition to sample IDs.
  - Recorded input file SHA256 digests in comparison reports.

### P1: Artifact Validation Bypass via Legacy Status Tag
- **Defect Identified:**
  - `load_threshold` previously bypassed split checks when `calibration_status == 'previously_inspected_external_data_not_independent_test'`, allowing files with `source_splits=['external_test']` to be accepted.
- **Implemented Fix:**
  - Consolidated threshold loading into [load_validated_threshold](file:///g:/Master%27s%20Of%20Science%20Computer%20Engineering/thesis%20deepfake%20detection/Thesis%20Revisions%20SP/First%20revesion/Novel%20Deepfake%20Detection/evaluation/generalization.py).
  - Enforced forbidden split check **first**: any artifact with forbidden splits (`test`, `external_test`, etc.) is immediately rejected, regardless of status tags.
  - Strictly validated legacy schema: requires consistent threshold fields (rejects files where `threshold` conflicts with `logit_threshold`), valid label mapping (`{'real': 0, 'fake': 1}`), known score space, and FP32 precision.

### P2: Probability Threshold 1.0 Decision Boundary Disagreement
- **Defect Identified:**
  - For finite logits and saturated probabilities [1.0, 1.0], threshold 1.0 caused `binary_metrics` to predict fake (`p >= 1.0`), while `ClassificationMetrics` predicted real (`p > 1.0` or `< 1.0`).
- **Implemented Fix:**
  - Consolidated binarization into [compute_binary_predictions](file:///g:/Master%27s%20Of%20Science%20Computer%20Engineering/thesis%20deepfake%20detection/Thesis%20Revisions%20SP/First%20revesion/Novel%20Deepfake%20Detection/evaluation/generalization.py).
  - Mathematically, for finite logits, probability threshold 1.0 corresponds to $\tau_z = +\infty$, which predicts no fake samples (`np.zeros`).
  - Routed `binary_metrics`, `ClassificationMetrics`, `GeneralizationEvaluator`, and confusion matrix plots through `compute_binary_predictions`.
  - Enforced rejection of unknown score spaces (e.g. `'custom'`).

### P2: Logit Threshold Forwarding to Video Aggregates
- **Defect Identified:**
  - `evaluation/generalization.py:summarize()` forwarded image-level logit thresholds to video aggregates computed as mean probabilities, causing unit collision.
- **Implemented Fix:**
  - When `score_space == 'logit'`, video aggregation marks video-level metrics as `unavailable` with documented rationale:
    `video_level: {'status': 'unavailable', 'reason': 'video-level metrics require probability thresholds or video-calibrated logit thresholds'}`.
  - Preserved documented mean-probability video aggregation without silently altering units.

### P2: Robustness CLI Logit Tracking
- **Defect Identified:**
  - `evaluation/robustness_cli.py` discarded raw logits from the detector, passing only probabilities to `summarize()`.
- **Implemented Fix:**
  - Extracted canonical FP32 logits from `detector(pixels)`.
  - Integrated `load_validated_threshold` and propagated `logits` and `score_space` to `summarize()`.
  - Exported FP32 logits into robustness prediction CSVs.

### P2: Test Hardening and Verification Coverage
- **Defect Identified:**
  - Previous trainer smoothing tests used zero logits (where BCE loss is identical for any target), failing to verify actual smoothing shrinkage or gradients. Notebook tests did not parse bash commands.
- **Implemented Fix:**
  - Added tests with nonzero asymmetric logits (e.g., -2.0, 3.0), verifying exact mathematical shrinkage loss and analytical gradients:
    $$\frac{\partial \mathcal{L}}{\partial z} = \sigma(z) - y_{\text{smooth}}$$
  - Added test verifying optimizer step updates classification head weights under smoothed loss.
  - Added CPU distributed gathering alignment tests with uneven and empty worker shards.
  - Added tests parsing and validating actual Colab bash training commands and end-to-end orchestration.

## 4. Invariants & Compatibility Contracts

1. **Default Training Behavior ($s = 0.0$):**
   - `--rgb_label_smoothing` defaults to `0.0`. Omitting the flag preserves bit-level identity with existing baseline cross-entropy loss.
   - Nonzero smoothing requires explicit `--rgb_label_smoothing <s>` and is strictly constrained to $0.0 \le s < 0.5$ on `Wang2020_128`.
2. **Training vs. Evaluation Invariant:**
   - Smoothing is strictly applied when `bool(self.training and getattr(self.model, 'training', False)) == True`.
   - Calling `eval()` or entering validation reverts immediately to exact hard binary cross-entropy.
   - Target labels are never mutated in-place.
3. **Score Space Invariant:**
   - Standalone evaluation defaults to `score_space='probability'`.
   - Logit calibration emits `score_space='logit'`.
   - Logit thresholds $\tau_z$ are evaluated directly against logits without sigmoid transformation.
   - Legacy baseline threshold (`25.587146759033203`) remains fully functional and verified.
4. **Security & Data Split Invariant:**
   - Forbidden splits (`test`, `external_test`) can never be calibrated or relabeled, even if a legacy status tag is present.
   - Folder validation export labels unverified data as `split='dev'`, `folder_role='dev'`, and `independence_status='unverified_dev_folder'`.
